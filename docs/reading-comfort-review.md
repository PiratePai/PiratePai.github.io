# 连续阅读与文章排版调整

用户反馈上一版章内分页过于琐碎，各章节的排版与配色不利于阅读。本轮调整全部 16 篇文章的共享阅读器，保留正文、原图、引文和语义锚点。

## 分页取舍

此前 196 个章节／导读／附录被拆成 722 页，部分小节和很短的结尾说明也占一页。现在采用以下规则：

- 短章节整章展示；长章节读到足够内容后，才在小节或完整内容块边界分页。
- 相邻短页合并；跨结构容器的短导语、章末说明也并入上下文，避免只有几十字的一页。
- 图与图注、公式块、交互演示、完整列表项仍作为完整节点；参考文献长表保留表头及完整行。
- 单页章节在侧栏直接点击；只有多页章节需要展开。移除正文上方重复的翻页栏，保留固定工具栏与页尾翻页。

调整后共 **294 页，减少约 59%**，平均每章约 1.5 页。分页在桌面与手机使用相同边界，主题切换也不会改变所在页。

## 排版与配色

- 正文区域最大 920px，桌面左右留白后文字宽度约 816px；正文桌面 17px、手机 16px，行高约 1.95，避免过长行和拥挤段落。
- 标题采用实色与适中字重，取消渐变大字和到处高亮的强调；概念主要靠字重、段距与层级区分。
- 默认采用柔和深灰底、灰白正文与低饱和蓝色链接；新增纸白浅色切换，跨文章保存偏好。分别处理旧样式留下的深底提示框、标签、引文、图注及参考文献颜色。
- 引文采用稍小但可读的字体及弱背景，提示框按说明、类比、小结区分；表格支持局部横向滚动，代码采用固定深色背景。
- 论文原图使用白色底板，内嵌 SVG 与交互演示保留绘图背景；不对原图改色。重置旧文章的重复章节卡片，避免嵌套边框和留白挤窄正文。
- 固定工具栏保留翻页、页码、主题和全文切换；适配 320px 窄屏，并移除会遮住手机正文的旧悬浮回顶按钮。
