# 逐篇开篇审查清单（2026-11-19）

按 2026-11-19 改版要求，逐篇检查开头是否回答**动机、机制主线、适用边界**三件事，问题入口、首个算例、关联实验与证据是否可达。本文是处理清单与后续依据，不宣称逐篇完成全文重核。审查方法：读取每篇文章的开篇区（第一个 `h2` 起的前几个语义块）与首页问题入口的对应关系；结构要素（开篇锚点、主线句、一页纸地图/表 0-1、大事记、边界表述）以源码为准。

## 开篇类型

- **A 型（导读四问）**：`s0 导读` 含一句话主线与"本文回答四个问题"+ 一页纸地图/表 0-1 + 大事记 + 阅读路径卡。2026-11-04 之后的新文与多篇修订文属此类。
- **B 型（TL;DR/导读+术语）**：早期综述以"太长不看版 / 导读：收益与代价 / 为什么需要 X / 三个现象"开场，动机充分；**适用边界多在各章"常见误用/小结"而非开篇**。
- **C 型（系统解剖）**：开篇先给执行链/一页纸地图（每一步执行什么、花掉什么），机制在链路上展开。
- **D 型（研究方案/登记）**：开篇给方法/判断分工与证据分层，明确待验证假设。
