# 首页阅读手册与站内搜索

首页按已确认的 Impeccable「分阶段阅读手册」实现，经本地测试后合入仓库。首页从引擎全景、并列核心优化到性能评估解释阅读顺序，旁注连接草稿后训练、MoE、并行和视觉专题。窄屏中关联提示紧跟导读，位于综述目录之前。

保留原有 15 篇首页条目的链接、标题、摘要、日期与顺序，补入仓库已有的免训练自动调优专题，目录与搜索覆盖全部 16 篇。未改动文章正文和共享阅读器。原有浏览量口径仍注明与 GitHub 主页共用计数器。

## 搜索行为

- 搜索标题、章节和正文；中文及英文大小写、全角字符和连字符均可处理。
- 每篇返回最相关章节，附上下文摘要、匹配词高亮和章节直达链接。
- 输入框支持 `/`、`Ctrl` / `⌘` + `K` 聚焦、`Esc` 清空；查询可通过 URL 的 `q` 参数分享。
- 静态索引约 1.2 MB，首次使用时加载。加载失败仍搜索首页标题与摘要，并提供重试；无 JavaScript 时保留完整目录和导读。
- 搜索使用文本节点绘制，不将输入拼成 HTML。多个词须共同匹配同一章节。

`scripts/build-search-index.py` 仅依赖 Python 标准库，从现有文章提取正文和有效锚点，排除脚本、样式与导航。更新文章后应重建索引，`--check` 可检查过期状态。

## 验证记录

- `python scripts/check-site.py`：17 页的本地链接、锚点、资源及 26 段内联脚本通过。
- `python scripts/build-reader.py --check`：16 篇文章无变更。
- `python scripts/build-search-index.py --check`：16 篇的静态索引一致。
- `node --test scripts/test-site-search.cjs`：6 项测试通过，覆盖索引锚点、中文、英文规范化、章节定位、组合词和空输入。
- 浏览器验证章节跳转、返回后查询恢复、清空、空结果、输入转义、快捷键、加载更多、手机导航、160 字符长查询、503 回退与重试恢复。
- 1440、1280、390、375px 布局无横向溢出；正文与控件文字对比度检查通过。
- Impeccable 静态检测仅运行一次；发现的跳转链接悬停对比度已修复。
- 独立复核提出三项修订：窄屏关联信息提前、自托管标题字体、元信息移到标题之后。三项均经修订复核判为 resolved，最终 disposition 为 `ship`；此结论的范围是这三项修订，不代表批准 PR 或部署。
