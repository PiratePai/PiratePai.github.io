## 主线与分支

通用推理主线：注意力 → KV Cache → 量化 → 投机解码 → 并行 → 服务 → 引擎集成 → 仿真 → 调优。这里的顺序是概念组织建议；例如量化与投机解码可以独立选读，二者不是严格的先修关系。

- 专家与异构部署：注意力 → MoE；结合缓存、量化与并行，再读CPU-GPU混合推理。
- 草稿训练：投机解码 → 草稿后训练。关注RL协同时，再参考Agent与强化学习。
- 视觉与实时生成：注意力 → ViT稀疏化 → 实时世界模型，同时参考缓存和服务专题。
- 计算深度：注意力与推理流程 → Loop Transformer；它不是通用部署优化的前置课程。

## 调整理由

此前L0–L6的技术分类混合了模型结构、算法、存储与系统集成，容易被误读为学习顺序。现在去掉首页的L编号，使用明确的五部分目录与第1–16篇定位。

定制推理引擎从默认入门起点移至系统部分：文章涵盖的算子、缓存、并行和服务概念需要共同背景。已有工程经验的读者仍可从页边的引擎总览入口定位问题。

MoE前移并标为专家支线基础；草稿后训练紧跟投机解码；并行先于服务与集成；性能仿真先于自动调优。Loop、视觉生成和Agent工作负载单列为按需进入的研究延伸，避免将复杂分支当作通用推理的必读前置。
