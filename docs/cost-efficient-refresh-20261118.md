## 叙事重排与新增章节

- **主公式升级**（2.1）：`$/M tokens` 升级为单位有效产出成本 `C_unit = C_total ÷ V_valid`，明确分子含全部已付费资源（含空闲与失败）、分母只计通过质量/SLO/任务成功过滤的产出，且单位（任务、有效 token、图像、视频秒）不同不能跨业务横比；随之给出六个常见陷阱（加卡、大 batch、缓存压缩、少步/小模型、质量非线性、过时/失败产出）与"成本最小 s.t. 服务目标 / 固定预算最大化有效产出"两种问法的换算关系。
- **新增 2.7 成本账本**：七组资源项（算力供给/通用资源/容量占用/切换成本/失败与浪费/质量补偿/任务链附加）+ 统计窗口与分摊规则 + 能耗、TCO、计费与售价三口径分离。
- **新增 9.1 两层指标栈**：算子/模型、状态/内存、引擎执行、服务、业务五层指标表 + 每类降本方法的"何时有用→如何作用→改善哪个账本项→付出什么代价→怎样避免伪收益"登记表。
- **新增 4.5 视觉与多模态**：VLM 视觉 token 经济（剪枝评测口径、视觉 KV 缓存、多流稳态成本）、扩散少步非无损、vLLM-Omni 与扩散服务缓存——补齐站内 VLM/视频/采样方向在本篇的缺口。
- **新增 6.5 任务链级**：agent 负载 batch=1、KV 增长主导成本、命中/未命中不对称与亚稳、客户端×服务端联合账本、Evolving Infra 等系统层进展——六层账本新增"任务链级"。
- **新增第 8 章视频案例**：以 PixVid（arXiv:2611.17336v1）为"吞吐、响应和成本不同"的单一案例——control-to-screen 与 TTFC/帧间隔/FPS 的区分、块等待的结构性下限（0–688 ms 等待 + 151/543+205 ms 生成的论文计时口径）、缩块的质量与算术强度代价（FVD 53.8→118.6、Turn 0.70→0.11、每帧 DiT 3× FLOPs）、吞吐越过播放线不保证响应、约束优化公式与教学小算例、质量指标不是线性效用。

## 错漏修订

1. **1.3 节教学账目错误（实错）**：原句"每成功成本反而从 6.67 降到 7.5 之外更低的档位"数学方向错乱（7.5 > 6.67），且自造"2 积分/次、30%→80%"数字与评测篇表 4-2 不符。已改为对齐评测篇口径：single 2、best-of-4 ≈6.67、adaptive 4（积分/成功），结论表述为"更多预算可买更高成功率、却推高每次成功成本"。
2. **引擎版本过期（实错）**：原 meta 写 vLLM v0.32.0（2026-11-15 快照即已过期，v0.33.0 于 11-02 发布）。当日核验后改为 v0.34.0（2026-11-16），并补 TRT-LLM v1.2.1 与 vLLM-Omni v0.32.0。
3. **图 2-1/2-2 与主公式对齐**：静态管道与交互图解从"资产→填充→goodput→单价→质量调整"改为"C_total→填充率→总产出→V_valid 过滤→C_unit"，旁路改为"空闲抬分子 / 失败与过时砍分母 / 命中压分子"。
4. **一致性与交叉引用**：五层→六层（导读地图、类比框、缓存级引言、index 问题路由）；2.x 重编号后同步 9.2 仪表盘、6.4 能耗引用等处的章节号；代码/图编号（图 9-1、代码 9-1）同步。
