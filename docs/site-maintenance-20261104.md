# 2026-11-04 首页、日期与发布资源维护

本轮对应网站审阅的第 4、5、6、7 项：更新信息一致性、首页入口、搜索/分享元数据及公共资源。研究正文与既有引用内容保持不变，没有把本次界面维护标作新一轮文献核验。

## 日期与变更记录

`data/articles.json` 是元数据来源。首次发布日期取自每篇在仓库中的首个提交，并保存完整提交 SHA；这与原稿撰写日期分开。内容更新取最后一条实际内容变更的日期；最近核验保留其局部范围。11 月 3 日的来源增补覆盖 16 篇，11 月 4 日的图解改动涉及 7 篇，其中四篇核心图有新的来源核验，其他图解排版不扩大核验范围。

生成页头日期与折叠变更记录，每条链接直达实际章节并提供范围说明。首页目录日期、最近更新、结构化数据和 sitemap 使用同一份数据。构建不会自动改成当天日期。

## 首页与分享

首屏提供从零学习、按问题查找、最近更新三个入口。四类问题连接显存、延迟、并发与部署专题；保留五阶段顺序与完整目录，移除重复的右侧路线。手机首屏可以直接开始阅读。

首页及 16 篇生成独立 description、canonical、Open Graph 和 JSON-LD；文章包含实际发布日期和内容更新日期。共用 1200 × 630 PNG 分享图，提供包含 17 个规范地址的 sitemap 与 robots。没有把这些元数据等同于搜索引擎收录保证。

## 公共资源

阅读器 CSS/JS、主题、WOFF2 字体、动画调度器和四张核心图的公共代码改用同源资源。CSS/JS 引用附带内容摘要版本，文本摘要按 LF 规范化，Windows 与 Linux 构建一致。动画调度器保持在内联演示之前同步加载，避免改变初始化顺序。仍保留完整 HTML 正文和无脚本目录；离线使用需保留相对目录结构。

搜索仍首次聚焦时加载。新增 gzip 索引，支持浏览器原生解压时优先使用；缺失、损坏或不支持时回退普通 JSON。服务器已透明解压时不重复解压；取消请求不另起回退请求。既有标题摘要回退、重试、关键词和排序保持原样。

相对合并前提交 `6613d67`，16 篇 HTML 的本地原始字节合计约 4.23 MB → 2.79 MB，减少约 34%。完整索引约 1.24 MB，gzip 约 561 KB，压缩约 55%；正文索引内容未删减。这是静态体积对比，不是实测加载耗时；共享资源首次请求仍需下载。
