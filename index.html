    通用推理主线

    这是一条精读路线，不要求逐篇读完所有分支。

    注意力 → KV Cache → 量化 → 投机解码 → 并行 → 服务 → 引擎集成 → 仿真 → 调优

    需要时进入支线

    MoE → 混合推理关注稀疏专家与资源受限部署时，补读这条路径。
    投机解码 → 草稿后训练先理解验证机制，再讨论如何训练更合适的草稿。
    注意力 → ViT 稀疏化 → 世界模型视觉生成支线还会用到缓存与服务系统知识。
    Loop Transformer / Agent 与 RL分别展开计算深度和训练、任务闭环，不是通用推理主线的必读前置。

    为什么引擎放在后面？

    定制推理引擎综合了算子、缓存、量化、并行与调度。已有工程经验时，可以先用引擎总览定位问题；初学者按左侧顺序补齐基础更容易对照各层职责。
